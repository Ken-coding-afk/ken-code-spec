# 文档目录

本目录用于沉淀项目概览、需求、设计、实施计划、决策、变更和术语。长期说明文档统一使用 `spec-*.md` 命名。

## 文件索引

- `spec-overview.md`: 项目概览
- `spec-requirements.md`: 需求说明
- `spec-design.md`: 设计说明
- `plans/`: 大改动的方案文档、执行文档及其模板
- `decisions/`: 决策记录
- `changes/`: 变更记录
- `spec-glossary.md`: 术语表

普通改动不需要创建正式计划文档。大改动的文档命名和格式见 `plans/README.md`。
